## Goal

This task enforces the non-negotiable from spec §Non-Negotiable Product Properties: "Every stale or contradicted memory is surfaced as such, not hidden behind recency." It implements the label-discipline layer that sits between the verifier (T48–T51) and every consumer that produces a workflow bundle (Phase 4 retrieval, Phase 8 workflow engine, Phase 10 review UI). A memory in `stale`, `contradicted`, `superseded`, `expired`, or `invalidated` MUST never appear as trusted guidance in any bundle; if surfaced at all, it must carry an unambiguous label and live in a separately-tagged section so an assistant cannot misread it as authoritative. Phase 7 DoD is binding: "stale or contradicted memory cannot appear as normal trusted guidance."

## Steps

1. Read spec §Non-Negotiable Product Properties bullet on stale surfacing + §Verification Engine outputs + §Risks Stale Memory Leakage. Copy all three into the top-of-file doc comment on `verification/surfacing.rs`.
2. In `verification/surfacing.rs`, define `pub enum BundleSection { Trusted, Stale, Contradicted, Superseded, Expired, Invalidated, InReview, Unverified }` and `pub struct LabeledMemory { memory_id, section: BundleSection, label_reason: String, content }`. The `Trusted` section is reserved for `Verified` memories only.
3. Implement `pub fn classify(memory: &Memory) -> BundleSection` — a total, deterministic mapping from `VerificationStatus` to `BundleSection`. Exhaustive `match` (no `_` arm) so adding a new state forces an explicit decision.
4. Implement `SurfacingPipeline::partition(memories: Vec<Memory>) -> SurfacedBundle` returning `SurfacedBundle { trusted: Vec<LabeledMemory>, advisory: Vec<LabeledMemory> }` where `advisory` carries every non-trusted memory tagged with its `BundleSection` and a one-line `label_reason` (e.g. "File `src/foo.rs` line 42 content changed since 2026-04-01"). The advisory list is what callers MAY display under an explicitly-labeled section; the trusted list is what they may treat as authoritative.
5. Forbid stale memories from `trusted`: a debug-assertions invariant inside `partition` panics if any non-`Verified` memory leaks into the trusted list; release builds filter and emit `tracing::error!("stale_in_trusted_bundle", memory_id, status)`.
6. Suppress stale memories from ranking promotion: extend the existing ranker signal list (from Phase 4) to include `verification_status` as a hard precondition — only `Verified` enters the trusted bundle's top-N. Non-verified memories may still be returned in the advisory list, ranked separately.
7. Add a `SurfacingPipeline::format_reason(memory, verdict) -> String` helper that produces the human-readable `label_reason` consistently across all callers. Single source of truth for label text — no caller composes its own string.
8. Define the contract surface (`pub trait BundleProducer { fn surface(memories: Vec<Memory>) -> SurfacedBundle; }`) so Phase 4 retrieval (R33-era code) and Phase 8 workflow tools both implement the same interface and cannot diverge.
9. In `verification/surfacing_tests.rs`, write tests that: (a) `Verified` memories land in `trusted`, every other state lands in `advisory` with the matching `BundleSection`, (b) the debug-assertions invariant fires if a test seam injects a `Stale` memory into `trusted`, (c) `label_reason` is non-empty and references the verifier's structured reason payload from T48/T49/T50/T51 (file id, span, scope, expiry), (d) the ranker top-N excludes every non-`Verified` memory regardless of score, (e) `classify` covers all eight `VerificationStatus` variants (exhaustiveness).

## Coding-standard checks

- File length ≤800 lines per file.
- Function length ≤50 lines, nesting ≤3, cyclomatic ≤10. `classify` is a flat `match`; `partition` is a single pass + invariant check.
- Single source of truth: every bundle-producing surface implements `BundleProducer` and goes through `SurfacingPipeline::partition`; no caller composes a trusted-versus-advisory split manually. `format_reason` owns the label-text format.
- Error handling: typed `SurfacingError` for the (small) failure modes (ranker integration not initialized). No bare `unwrap`. Stale-in-trusted is a `tracing::error!` + filter in release, panic in debug.
- Naming: `BundleSection::Trusted`, `LabeledMemory`, `partition`, `format_reason`. No `Manager`/`Helper`.
- Schema parity: `BundleSection` variants map 1:1 to `VerificationStatus` variants; if a new status is added, `classify` will fail to compile (exhaustive `match`).
- No `TODO`, `FIXME`, `XXX`, commented-out code, or unjustified `#[allow(...)]`.
- Observability: every release-mode stale-in-trusted filter emits `tracing::error!("stale_in_trusted_bundle", memory_id, status, caller_module)`; partition counts emit a `tracing::debug!` per call.
- Doc citation: file-top comment cites `## Non-Negotiable Product Properties` "Every stale or contradicted memory is surfaced as such", `## 8. Verification Engine` outputs list, and `## Risks — Stale Memory Leakage` (per `lattice/CLAUDE.md` § Markdown Heading References).
