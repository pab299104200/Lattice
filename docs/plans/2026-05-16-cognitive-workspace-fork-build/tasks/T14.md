# T14 — Phase 2 — Event reader/query API (filter by task/session/workspace/branch)

**Phase:** 2
**Type:** backend
**Model class:** balanced

**Standards:** Cadres coding standard; Lattice project rules.

## Goal

This task exposes the read side of the event log. It defines a typed query builder for filtering by task, session, workspace, branch, kind, and time range; reconstitutes full `EventEnvelope` values (with payload inlined from either `payload_inline` or the `event_payloads` spillover join); and enforces bounded result sets so a single query can never scan the full log. The reader is the substrate that consolidation (Phase 6), verification (Phase 7), retrieval (Phase 4), and metrics (Phase 9) all sit on. Without it, the event log is write-only.

## Steps

1. In `events/query.rs`, define `pub struct EventQuery` as a builder: `task(task_id)`, `session(session_id)`, `workspace(workspace_id)`, `branch(branch_ref)`, `kind(kind)`, `kinds(&[kind])`, `after(ts)`, `before(ts)`, `limit(n)`, `order(QueryOrder::OldestFirst | NewestFirst)`. Builder methods consume `self` and return `Self` for fluent composition.
2. Require at least one of `task`, `session`, or (`workspace` AND `branch`) on every query — enforce in `EventQuery::execute` with `EventQueryError::Unscoped`. The reader must never run a full-log scan.
3. Enforce a default `limit` of e.g. 1000 and a hard ceiling of e.g. 10_000; if the caller exceeds it, return `EventQueryError::LimitTooLarge { ceiling }`. Document the ceiling rationale in the module doc.
4. In `events/reader.rs`, define `pub struct EventReader { store: Arc<EventStore> }` and `pub fn EventReader::execute(&self, query: EventQuery) -> Result<Vec<EventEnvelope>, EventQueryError>`.
5. Translate the builder into a parameterized SQL string that uses the most-selective index available given the predicates (e.g. `task` => `idx_events_task`; `session` => `idx_events_session`; `workspace + branch` => `idx_events_workspace_branch`; with optional `kind` filter applied in WHERE). Never `format!` predicates — bind every parameter.
6. Reconstitute payloads: for each row, if `payload_inline IS NOT NULL` deserialize from inline bytes; if `payload_spill_id IS NOT NULL` JOIN against `event_payloads` (or do a second query keyed by row_id) to load bytes. Validate the loaded bytes hash to the row's `payload_hash`; on mismatch return `EventQueryError::PayloadCorruption { event_id, expected, actual }` — never silently return the wrong payload.
7. Provide a streaming variant `EventReader::stream(&self, query: EventQuery) -> impl Iterator<Item = Result<EventEnvelope, EventQueryError>>` for callers (replay, compaction) that must process more than `limit` rows without buffering them all.
8. Add a convenience method `EventReader::tail(&self, scope: TaskScope | SessionScope, n: usize) -> Result<Vec<EventEnvelope>, EventQueryError>` that returns the most recent `n` events for the scope in newest-first order — used by `expand_context` and the human review UI later.
9. Define `EventQueryError` as a typed enum: `Unscoped`, `LimitTooLarge`, `Storage(EventStoreError)`, `Serde(serde_json::Error)`, `PayloadCorruption { event_id, expected: PayloadHash, actual: PayloadHash }`.
10. In `events/reader_tests.rs`, write tests covering: task-scoped query returns only the task's events; session scope likewise; workspace+branch scope likewise; missing scope returns `Unscoped`; limit ceiling enforced; payload corruption (manually flip a byte in `event_payloads`) returns `PayloadCorruption`; streaming variant yields the same events as `execute` in order.

## Coding-standard checks

- File length ≤800 lines per file.
- Function length ≤50 lines, nesting ≤3, cyclomatic ≤10.
- Schema parity: the reader never invents columns; every SELECT lists the columns defined in T12's `schema.sql`.
- No silent error handling — payload-hash mismatches return a typed error; never log-and-continue.
- No `TODO`, `FIXME`, commented-out code.
- For SQLite: prepared statements with `rusqlite::params!`; no SQL string interpolation; index hints (`INDEXED BY`) only when measured query plans demand it, with a comment citing the EXPLAIN.
- Use `tracing::debug_span!("event_reader.execute", scope = ?scope)` and emit `tracing::warn!` on payload corruption.
