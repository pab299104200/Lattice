## Goal

This task is the Phase 7 backend review. It audits T48–T53 against the spec's verification contract, the §Non-Negotiable Product Properties bullets that verification directly touches (stale surfacing, no silent broad reads), the §Risks Stale Memory Leakage and Scope Leakage controls, and the coding standard. The review must produce a verdict on whether Phase 7 is ready to ship — every later phase (Phase 8 workflow engine, Phase 10 review UI) consumes the contract surfaces this phase defines, so a failed review blocks them. A pass/fail decision without cited evidence is not a review.

## Spec excerpts that drive this task

> Phase 7 DoD: "stale or contradicted memory cannot appear as normal trusted guidance; verification results are explainable and queryable."

> §Verification Engine outputs: `verified`, `unverified`, `in_review`, `stale`, `contradicted`, `superseded`, `expired`, `invalidated`.

> §Non-Negotiable Product Properties: "Every stale or contradicted memory is surfaced as such, not hidden behind recency."

> §Risks — Stale Memory Leakage: "tests that stale memory cannot rank as trusted."

> §Risks — Scope Leakage: "scope-aware queries, enforced filters in store APIs, and negative tests."
