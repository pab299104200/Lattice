**Phase:** 6

**Standards:** Cadres coding standard; Lattice project rules (`/home/pete/cadres/lattice/CLAUDE.md`, `AGENTS.md`).

## Goal

This task ships the cross-job integration test suite that proves Phase 6's invariants hold when all consolidation pieces run together: proposals from every job type land in `consolidation_proposals` without silent writes, apply/reject decisions route through the runtime correctly, replay reconstructs the same memory state, the bounded queue drops with warnings on overflow, malformed LLM responses emit `ConsolidationFailed` events while leaving prior memory unchanged, and high-scope proposals reach the manual-review queue instead of auto-applying. Unit tests in T39–T45 cover each module in isolation; this task wires them end-to-end so the spec's Phase 6 DoD ("consolidation is auditable, reversible, and test-covered") is demonstrably met.

## Spec excerpts that drive this task

> Phase 6 DoD: "completed tasks produce useful episode memories; repeated successful traces produce procedural memories; consolidation is auditable, reversible, and test-covered."

> "every background consolidation pass is recoverable, replayable, and observable."

> "failed or malformed LLM responses must leave the prior memory state unchanged and emit a consolidation failure event"

> "consolidation queue depth must be bounded; when the queue is full, new jobs are dropped with a log warning rather than stalling the daemon"

## Steps

1. Read spec §Phase 6 DoD and §Testing Requirements. Copy the four invariants this suite must demonstrate into the top-of-file doc comment on `integration_tests.rs`.
2. Build a `ConsolidationHarness` helper at the top of `integration_tests.rs` (or a sibling `integration_test_support.rs` if it grows): seeds a temp SQLite store with the Phase 2/3/6 schemas, registers a fake `LlmDriver` whose responses are scripted per test, wires the T39 runtime, T44 review queue, and T45 replay driver. Tests reuse the harness so each individual test stays ≤30 lines.
3. Write `test_synchronous_session_consolidation_emits_proposal_not_silent_write` (covers T40 + T39): run a small task slice through `SessionConsolidator::on_task_complete`, assert a `CreateMemory` proposal exists in `consolidation_proposals` with status `pending`, assert the memory store still has zero `EpisodeMemory` rows for that task, then apply the proposal and assert the memory appears AND a `MemoryConsolidated` event is in the event log.
4. Write `test_deterministic_supersession_proposal_apply_then_reject_round_trip` (covers T41): seed two overlapping memories, run `SupersessionCandidates::scan`, assert one `Supersede` proposal is pending, apply it, assert the older memory's status is `superseded` AND a `memory_links` edge points to the newer, then call `ReplayDriver::reverse(proposal_id)` and assert the status flips back and the link is gone.
5. Write `test_llm_episode_job_well_formed_response_emits_proposal_with_provenance` (covers T42 + T43): script the fake driver to return a well-formed JSON episode summary, run `EpisodeSummaryJob::run` in `Background` mode, assert a proposal exists with `provenance.is_some()`, `provenance.model == "fake-llm"`, and matching `prompt_sha256` / `response_sha256`.
6. Write `test_llm_malformed_response_leaves_memory_unchanged_and_emits_failure_event` (covers T42 malformed-handling): script the driver to return invalid JSON, assert zero proposals enqueued, zero memory mutations, and exactly one `ConsolidationFailed` event with `error_kind = MalformedResponse`.
7. Write `test_llm_synchronous_mode_is_forbidden_and_driver_never_called` (covers T42 mode guard): attempt `EpisodeSummaryJob::run(ctx { mode: SynchronousPostTask }, …)`, assert it returns `Err(ForbiddenOnHotPath)`, assert the fake driver's call count is zero.
8. Write `test_bounded_queue_overflow_drops_jobs_with_warning_event` (covers T39 + T43): set `max_depth = 2`, enqueue 5 jobs of the same LLM kind, assert exactly 3 are dropped, exactly 3 `ConsolidationFailed` events with `error_kind = QueueFull` are emitted, and the `tracing::warn!` log surfaced (capture via a tracing-test subscriber).
9. Write `test_high_scope_proposal_routes_to_manual_review_queue` (covers T44): seed a `repo`-scope target memory, run a job that produces a proposal for it, assert the proposal is `pending` and visible via `ReviewQueue::list_pending(scope=Repo)`, assert it did NOT auto-apply.
10. Write `test_replay_from_genesis_reconstructs_memory_state` (covers T45): apply 10 mixed proposals through the runtime, snapshot the memory store hash, reset the memory tables, run `ReplayDriver::replay(FromGenesis)` with the provenance cache, assert the post-replay memory hash equals the snapshot hash AND the live LLM driver was never called.
11. Wire the suite via `mod integration_tests;` in `consolidation/mod.rs` under `#[cfg(test)]` (or a `tests/` sibling per crate convention — match `daemon/crates/lattice-core/src/memory/tests.rs` style).
