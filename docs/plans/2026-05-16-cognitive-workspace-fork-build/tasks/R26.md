# R26 — Contract gate — Identity ↔ Event Log ↔ Memory cross-layer contracts

**Phase:** Contract gate
**Type:** review
**Model class:** advanced
**Depends on:** R10, R18, R25
**Spec anchor:** [§Design Thesis](../../2026-05-16-cognitive-workspace-fork-plan.md#design-thesis)

## Purpose

This gate certifies the cross-layer round-trip contracts between the three first-class substrates the spec names: workspace identity, event log, and memory graph. Each layer was reviewed in isolation by R10, R18, R25; this gate proves they compose. Specifically: stable identity references serialize cleanly into event payloads, those payloads round-trip back to the same identity targets, and memory records link to stable identities (not transient names) so memory survives identity refactors and event replays. This gate is the contract that the rest of the build (retrieval, working memory, consolidation, verification) can assume. A failed verdict here blocks T27 (Phase 4 start) because no later layer can be trustworthy on broken cross-layer contracts.

## Review procedure

1. Verify identity references serialize cleanly into event payloads: pick each payload struct that embeds a `StableRef` (e.g. `FileRead`, `PatchApplied`, `MemoryRetrieved`, `ContextBundleReturned`, `DiagnosticObserved`); confirm serde output uses the canonical wire form from Phase 1 identity, not a path string or raw name.
2. Verify event payloads round-trip back to identity targets: take a serialized event, deserialize via `EventReader`, resolve every `StableRef` through the Phase 1 resolver, and confirm the resolution returns the same identity object that was written.
3. Verify memory links reference stable identities not transient names: take a `MemoryLink` with `target = MemoryLinkTarget::Symbol(SymbolId)`; rename or refactor the underlying symbol; confirm the link still resolves to the renamed symbol via the resolver, and that the link's `target_id` did not need to change.
4. Verify memory evidence anchors carry stable identities: confirm `EvidenceAnchor::FileSpan` carries `FileId` (not a path string) and `EvidenceAnchor::DocSection` carries `DocSectionId` (not a heading string).
5. Verify migration (T22) preserves identity references: pre-migration legacy memories that referenced files-by-path are post-migration memories that reference files-by-`FileId`; assert no path strings survive in `memory_evidence` or `memory_links` payloads.
6. Verify event capture (T15) records identity-typed references: instrument a representative tool call, assert the emitted event's `references: Vec<StableRef>` contains the right typed variants (no strings).
7. Verify replay preserves the contract: replay an event log from scratch (T17 + T24 fixtures) and assert that every reconstituted memory still has identity-resolvable evidence anchors after replay.
8. Verify schema-level enforcement: every column that holds an identity (`provenance_event_ids_json`, `event_id`, `memory_id`, `target_id`) is constrained to the right shape; no schema drift between the identity, event, and memory layers permits raw strings where typed ids are expected.
9. Add the cross-layer contract test file at `daemon/crates/lattice-core/src/contract_tests/identity_event_memory.rs` (create `contract_tests/mod.rs` if absent and wire it into `lib.rs`). Tests in this file exercise the round-trip end-to-end: identity → event payload → event store → event reader → memory writer → memory store → memory reader → identity resolver, asserting equality at every boundary.
10. Run `cd daemon && cargo test -p lattice-core --lib contract_tests::identity_event_memory` and confirm every test passes; record the test names in the review output.
