# T13 — Phase 2 — Event writer API + payload hashing + workspace scoping

**Phase:** 2
**Type:** backend
**Model class:** balanced
**Depends on:** T12
**Spec anchor:** [§Phase 2: Event Log Substrate](../../2026-05-16-cognitive-workspace-fork-plan.md#phase-2-event-log-substrate)
**Standards:** Cadres coding standard; Lattice project rules.

## Goal

This task implements the public writer that workflow tools, the MCP layer, and the consolidation engine use to append events. It computes the canonical payload hash (deterministic over sorted-key JSON of the typed payload), decides inline vs. spilled payload location based on a configurable size ceiling, enforces workspace scoping at the API boundary (the writer cannot accept envelopes whose workspace_id disagrees with the open store), and meets the spec's hot-path budget of P99 ≤5ms write latency on `prepare_change` and `get_context_capsule` paths. Without the writer, no event ever reaches the store.

## Spec excerpts that drive this task

> "event writer API … event payload hashing and optional payload spillover …"

> "event write adds no more than 5ms P99 to hot-path tool calls (`prepare_change`, `get_context_capsule`); large payloads spill to a side table rather than blocking the writer."

> "No silent broad workspace reads that bypass ignore rules or workspace boundaries."

## Steps

1. In `events/hashing.rs`, define `pub struct PayloadHash([u8; 32])` (BLAKE3 or SHA-256 — match whichever the rest of the crate uses; document the choice) and `pub fn hash_payload(payload: &EventPayload) -> PayloadHash`. The hash is computed over `serde_json::to_vec` of the payload with a deterministic key ordering (use `serde_json::ser::PrettyFormatter` is wrong here — use a canonical-JSON helper that sorts keys; if none exists, write one and unit-test it).
2. In `events/writer.rs`, define `pub struct EventWriter { store: Arc<EventStore>, workspace_id: WorkspaceId, inline_ceiling_bytes: usize }` and `pub fn EventWriter::new(store: Arc<EventStore>, workspace_id: WorkspaceId, inline_ceiling_bytes: usize) -> Self`. Default `inline_ceiling_bytes` to 4096 (documented in module doc with rationale).
3. Define the primary entry point: `pub fn EventWriter::append(&self, envelope: PartialEnvelope) -> Result<EventId, EventWriteError>`. `PartialEnvelope` contains the caller-supplied fields (kind, references, payload, summary, optional task_id, session_id, actor); the writer fills in `event_id`, `timestamp` (UTC monotonic via `chrono::Utc::now()` plus a per-session monotonic tiebreaker), `payload_hash`, and `payload_location`.
4. Enforce workspace scoping: if `PartialEnvelope::workspace_id` is set and differs from `self.workspace_id`, return `EventWriteError::WorkspaceMismatch` — do not silently coerce.
5. Decide payload location: serialize the payload, hash it, and if `bytes.len() <= inline_ceiling_bytes` set `PayloadLocation::Inline { bytes_len }` and insert payload bytes directly into the `events.payload_inline` column. Otherwise call `EventStore::insert_or_get_payload(hash, bytes)` and set `PayloadLocation::Spilled { row_id }`. Content-addressed dedupe is handled by T12's UNIQUE index on payload_hash.
6. Use a prepared-statement cache on the writer so repeated appends do not re-prepare the INSERT; document that the cache is per-writer, not global.
7. Instrument `append` with `tracing::trace_span!("event_writer.append", kind = ?envelope.kind)` and emit a `tracing::debug!` on every spill so operators can see hot-path payload-size pressure.
8. Add a synchronous-flush option for tests: `EventWriter::with_flush_policy(FlushPolicy::Sync | FlushPolicy::Batched { interval_ms })`. Default to `Sync` in tests, `Batched` in daemon use (configurable later in T15).
9. Define `EventWriteError` as a typed enum: `WorkspaceMismatch`, `PayloadTooLarge { ceiling: usize, actual: usize }` (if a hard cap is exceeded), `Storage(EventStoreError)`, `Serde(serde_json::Error)`, `Identity(IdentityError)`.
10. In `events/writer_tests.rs`, write tests covering: deterministic hash for equivalent payloads with key-order variation; identical payloads dedupe to one `event_payloads` row; inline vs. spill threshold honored exactly at the boundary; workspace mismatch returns `WorkspaceMismatch`; concurrent appends from two threads preserve monotonic `event_id`; sync flush returns only after the row is durable in WAL.
