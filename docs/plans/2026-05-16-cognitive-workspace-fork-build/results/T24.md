Issues encountered

- The existing memory lifecycle events did not carry enough state to rebuild `memories`, `memory_links`, and `memory_evidence` from the event log. I added replay snapshot payload support to `MemoryCreated`, `MemoryUpdated`, and `MemoryInvalidated`, plus reserved-event-id support in the event writer so snapshots can include the final persisted event references exactly.
- Link operations did not have dedicated store APIs. The test suite uses normalized link insertion plus lifecycle event emission through the existing transition writer, which is enough to prove contradiction, supersession, stale-state, and replay behavior without widening task scope beyond the required integration support.
- The shared memory-graph test harness was in-memory only. I moved it to isolated temp-backed SQLite fixtures to satisfy the task requirement for per-test temp DBs.
