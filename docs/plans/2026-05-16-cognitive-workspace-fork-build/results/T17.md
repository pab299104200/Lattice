## Issues encountered

- The initial replay tests exposed that `EventReader::stream` was ordering by timestamp first, not by append-only `event_id`. Fixed by changing paging and ordering to `event_id` order.
- The corruption tests exposed that `Bootstrap::load` had no “newest valid snapshot” fallback and surfaced snapshot hash errors only through `SnapshotError`. Fixed by adding `BootstrapError::ContentHashMismatch`, mapping truncated-body reads to hash mismatch, and falling back to prior valid snapshots in the same directory.
- The first budget harness failed because the three ignored perf tests contended with each other and because the writer was doing redundant work on every append. Fixed by:
  - serializing the ignored budget cases with a global mutex
  - hashing already-serialized payload bytes instead of canonicalizing the same typed payload twice
  - caching spilled payload row ids per writer
- The task requested a failure-path assertion via capture wiring; the existing daemon capture test suite was extended to verify the session tail includes `ToolCalled` and failed `ToolResult` events for an error path.
