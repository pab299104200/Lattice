## Issues encountered

1. **Budget tests assert pass/fail but do not emit measured µs values.** To
   capture the P99 numbers required by the `## P99 budget evidence` section,
   I added temporary `println!` lines inside `assert_within_budget` and the
   combined-workflow assertion, ran the budget tests in `--release` with
   `--nocapture`, recorded the values, and reverted the edits. Final file is
   byte-identical to T09 drop and re-verified green. (Captured numbers: 1 µs /
   1 µs / 1 µs / 108 µs vs budgets 2000 / 2000 / 2000 / 2462 µs.)

2. **Numeric `T11` slot already occupied.** The task spec wording "follow-up
   task opened in this build" suggested a numeric continuation, but `T11.md`
   already exists for Phase 2 event-model work. The build has an existing
   `T-followup-<review>-<letter>` convention (`tasks/T-followup-R05-A.md`)
   that I followed for the R10 follow-up. The review verdict and the
   follow-up task both name `T-followup-R10-A.md` consistently.

3. **Force-rebuild needed to surface compiler warnings.** Cargo's incremental
   cache hid the post-T09 warning state of the workspace; `cargo build` did
   not recompile any crate. I ran `cargo clean -p lattice-core` followed by
   `cargo build --release`, and additionally `touch crates/lattice-core/src/lib.rs`
   to force a clean recompile from the source tree. The resulting build was
   silent: zero warnings, zero errors, zero notes.

4. **Two redundant test modules exist for the resolver.** Both
   `identity/resolver_tests.rs` (the spec-mandated 10-case matrix from T09)
   and `identity/resolver/tests.rs` (a 3-case earlier scaffold from T07
   declared via `mod tests;` from `resolver.rs:731`) compile and pass. The
   3-case file restates behaviors already in the 10-case matrix; flagged as
   finding F-1 with cleanup folded into `T-followup-R10-A`.

5. **`resolve_test` is a public resolver method with zero direct tests.**
   The Phase 1 spec lists "tests" as one of the five resolution categories;
   the 10-case matrix covers paths, symbols, sections, and event refs but
   not the test-resolution path. Flagged as finding F-3 with two new test
   cases scheduled in `T-followup-R10-A`.
